# 历史记录（changelog）

本目录按日期保存矩阵与路线图的历史条目，**append-only**：只允许追加，不允许改写过往条目。

- 每条记录形如 `YYYY-MM-DD.md`，当日多条变更合并进同一文件。
- 文件内固定分节：`## 矩阵` / `## 路线图`，没有内容的分节省略。
- 无法判定日期的条目进入 [undated.md](undated.md)，不猜测日期。
- 现状事实不要写在这里；这里只保存带日期的变更记录。
